## 应用介绍

PhrasePerch 把常用文案和附件放进快捷菜单。回复消息、写邮件、填写表单或与 AI 对话时，调出菜单就能选择已经保存的内容。每个应用都可以准备自己的内容，并用分组整理。

## 使用方法

1. 打开 PhrasePerch，选择要使用的应用，添加文案或把文件拖入列表。
2. 切换到该应用的输入框，按住 Option 调出快捷菜单。
3. 移动鼠标选中内容，松开 Option 即可插入。

也可以设置组合快捷键，按一次打开菜单，再点击选用内容。更多操作见 [使用指南](docs/usage.md)。

## 安装

支持 Apple Silicon Mac，需 macOS 14 或更新版本。下载 DMG 后，将 PhrasePerch 拖入“应用程序”，首次启动时按引导完成系统授权。下载入口和详细步骤见 [安装与授权](docs/installation.md)。
