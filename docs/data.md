# 数据与备份

[返回 README](../README.md)

## 本机保存

应用规则、快捷内容、分组和偏好设置保存在：

```text
~/Library/Application Support/local.PhrasePerch/
```

配置修改会自动保存，写入使用原子替换，并保留最近三个有效配置备份。配置格式为版本 2，读取版本 1 的文案配置时会自动升级并保留原文件备份。静默启动、后台 Dock 和菜单栏显示偏好保存在本机 UserDefaults 中。

附件添加时会复制到数据目录的 `attachments/<资源ID>/<文件名>`，原文件移动或删除后仍可使用副本。复制条目会共享附件资源。回收时会保留当前配置、有效备份、剪贴板和进行中操作引用的附件；文件缺失时，可以在编辑区重新选择。

## 导出与导入

导出会生成 `.phraseperch` 备份包，包含当前配置和引用的附件副本。备份包包含实际文件内容，分享前请核对其中的附件。

导入支持完整备份包和旧版文案 JSON。含附件的配置需要使用完整 `.phraseperch` 备份包。应用会先校验并暂存导入内容，确认后替换配置；导入失败时保留当前数据。

## 剪贴板与插入

“文案使用剪贴板粘贴”默认开启。选择文案后，应用把正文写入剪贴板并发送一次 `⌘V`，正文会保留在剪贴板中。关闭该设置后，文案通过可写的 `AXSelectedText` 直接替换输入框选区。附件始终通过剪贴板粘贴。

在普通空白区域选择内容会执行复制。应用不发送 Return；单条文案上限为 64 KiB UTF-8。

## 交互诊断

设置页展示最近 20 次交互的阶段、耗时、定位来源和结果。诊断保存在内存中，日志不包含文案正文和输入框全文。
