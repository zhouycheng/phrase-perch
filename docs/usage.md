# 使用指南

[返回 README](../README.md)

## 准备常用内容

打开 PhrasePerch，选择要使用快捷内容的应用。首次启动会预建 Safari 和 ChatGPT 的空配置；其他应用可以通过“添加应用”加入。每个应用分别保存自己的内容和触发方式。

添加文案时填写标题和正文，标题用于菜单展示。正文支持中文、Emoji、Tab 和换行。点击内容行可以选中条目，行尾的开关和操作按钮可以单独使用。

添加文件可以点击工具栏的“添加附件”，也可以把一个或多个文件拖入内容列表。每个文件生成一个条目，初始标题使用完整文件名，之后可以改标题或替换文件。目标应用能接收的文件类型由该应用决定。

内容可以排序、启停或放入分组。分组支持嵌套，也可以和文案、附件一起排序；移除分组后，其中的内容会移回父级。

## 调出快捷菜单

默认按住 Option 约 120 毫秒打开菜单，移动鼠标选择内容，松开 Option 后插入。没有选中内容时松开会取消。修饰键可以在设置中改为 Command 或 Shift。

也可以录制组合快捷键，按一次打开菜单，再点击内容提交。再次按快捷键、按 Esc、点击菜单外部或切换应用都会关闭菜单。应用规则可以选择修饰键、快捷键，或同时启用两种方式。

菜单每页最多显示八个按钮，内容较多时会分页。把鼠标停在分组或翻页按钮上，稍候就会进入对应页面；“上一页”返回刚才访问的页面。菜单会根据屏幕空间调整每页数量，标题过长时会省略。标题显示上限可以在设置中调整为 1–30 个字符，默认 10 个。

展开位置可以选择鼠标或输入光标。光标位置不可用时，菜单会在输入框可见范围内或鼠标附近展开，并显示原因。

## 输入与复制

在输入框中选择内容会执行插入，在普通空白区域选择会复制内容。无法可靠识别的编辑器会进入“仅复制”模式，可以随后手动粘贴。

菜单打开时保留原输入焦点。目标、选区或权限变化时会取消本次操作；密码框和安全输入会显示提示。使用中文输入法时，请先提交候选文字，再调出菜单。插入失败或结果需要核对时，应用会在鼠标下方显示原因。

剪贴板设置和附件保存方式见 [数据与备份](data.md)。

## 窗口与后台运行

左键点击菜单栏图标打开主窗口，右键显示操作菜单。已最小化的主窗口会恢复，关闭主窗口后仍可使用快捷菜单。

“静默启动”默认开启：登录自启动时在后台运行，手动打开应用时显示主窗口。主窗口打开或最小化时显示 Dock 图标；关闭窗口后，由“后台运行时隐藏 Dock 图标”设置决定是否显示。后台运行时至少保留 Dock 或菜单栏中的一个入口。
